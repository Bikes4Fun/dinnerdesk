Recipe tags

Dashed tags are proposed: ✓ keeps one, × removes it (click ↺ to bring it back). Click a tag's name to rename it. Add a tag by typing a dimension and a tag, then Enter. Aim for 1–2 cuisines and 3–8 tags per recipe. Click a recipe, then J / K to move and R to mark it reviewed. Changes save in this browser as you go; Export tags writes them to a file.

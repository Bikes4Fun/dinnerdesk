# Working in this repository

Follow the shared repository workflow in [CLAUDE.md](CLAUDE.md).

- Make changes in a dedicated Git worktree on the designated feature or fix branch. Never edit, commit, or push changes directly on `main`. If the current checkout is on `main`, switch to the designated worktree before editing.
- Commit each small, coherent step after running its relevant checks. Push each commit promptly to the working branch on `origin`, including during longer tasks. Keep unrelated changes out of the commit and preserve published history.
